# 🎬 StreamSphere

A modern OTT streaming platform inspired by Netflix, built using React. StreamSphere provides a clean and responsive interface for browsing movies and TV shows with an engaging user experience.

## 🚀 Features

- 🎥 Browse movies and TV shows
- 🔍 Search functionality
- 📱 Responsive UI
- ⚡ Fast React-based frontend
- 🎨 Modern design with Tailwind CSS
- 🧭 React Router navigation

## 🛠️ Tech Stack

- React.js
- JavaScript
- Tailwind CSS
- React Router
- HTML5
- CSS3

## 📂 Project Structure

```
src/
public/
package.json
tailwind.config.js
postcss.config.js
```

## ⚙️ Installation

```bash
git clone https://github.com/sujith525/StreamSphere.git
cd StreamSphere
npm install
npm start
```
